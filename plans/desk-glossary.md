# План: словарь Trade Desk внутри приложения (📖 Словарь + подсказки)

Статус: **G1 и G2 сделаны** (2026-09-11, не закоммичены) — фича закрыта. Planning завершён 2026-09-11. Код — в новых сессиях Implementation (CLAUDE.md, «вариант 1»): **G1** (словарь в меню) и **G2** (подсказки на экранах), каждая — отдельной сессией. Коммит — только по явной просьбе, push — по просьбе. Воркер не меняется (деплой не нужен).

## Задача

В Trade Desk много терминов и чисел (R, R/R, ATR, фазы, флаги, «Что если?», зона, риск 1–5…). Пользователь попросил описание каждого с примером «зачем и как использовать». Сделан артефакт-справочник «Словарь Trade Desk» (https://claude.ai/code/artifact/d59acd2b-0ad4-413b-acc5-fbef4e617d8f); его исходник — **`plans/desk-glossary-content.html`** (93 термина + сквозной пример «одна сделка») — **источник текстов** для этой фичи. Встроить его в приложение.

## Решения пользователя (2026-09-11)
- **Объём:** словарь в меню ⋯ **и** контекстные подсказки на экранах — две фазы (G1, G2).
- **Язык описаний:** только русский (как текущая «❓ Справка»); заголовки и кнопки UI — двуязычные через `RT(ru,en)`.

## Ключевые принципы
1. **Один источник текстов** — `DESK_GLOSS` в новом файле `desk-gloss.js`. И словарь, и подсказки читают только его.
2. **Никаких захардкоженных порогов.** Всё, что есть в `SIG.CFG` (rrMin 2, rrWeak 1.2, nearPct 2, minStopAtr 1, stopBufAtr 0.5, corridorAtr 2.5, targetAtr 2, wideAtr 2, earnDays 3, rsiHot/Cold, squeezeDay/Vol, staleTgPct 50…), `DESK_IDEA_CFG` (nearZonePct 3, fvW 25/50/25, risk.atrPct/betaHi, whatIf.weightPct/sectorPct/ccyPct/staleMin, ana.devPct/peersMax) и `deskNorm(DESK)` (riskPct, riskCapPct), подставляется в текст из конфига в момент рендера. Поля записи — строки или функции `()=>string`. Смена порога → словарь меняется сам (тест это проверяет).
3. **Сквозной пример считается кодом**, а не пишется руками: `deskGlossStory()` прогоняет синтетические уровни через `SIG.tradePlan` / `SIG.limitForRR` / `deskTrailStop` и формулу размера — числа в тексте = результат функций (тест фиксирует: стоп 96, цель 109, R/R 2.25, 500 шт при риске 2 000; при правке CFG пример пересчитается, тест покажет расхождение).
4. Иллюстративные числа примеров (цена 100, капитал 200 000, bear/base/bull 80/115/140…) — статичны, это не пороги.

## Модель данных `DESK_GLOSS`
```js
const DESK_GLOSS={
  secs:[{id:'base',t:'Основа',lead:'…'},{id:'verdict',…},{id:'phase',…},{id:'flag',…},
        {id:'today',…},{id:'ideas',…},{id:'stock',…},{id:'book',…},{id:'journal',…},{id:'menu',…}],
  items:[
    {id:'rr', sec:'base', t:'R/R — прибыль к риску', aka:['rr','риск/прибыль','reward'],
     lbl:()=>…,            // необязательно: HTML метки как в приложении (dkPill/dkPhase/…)
     d:()=>'Сколько можно заработать до цели на каждую единицу риска…',   // 1–2 предложения; первое = текст подсказки G2
     f:'R/R = (цель − вход) ÷ (вход − стоп)',                              // формула (моноширинный)
     ex:()=>`Вход 100, стоп 96, цель 109 → 9 ÷ 4 = 2,25…`,
     use:()=>`≥ ${fmt(SIG.CFG.rrMin)} — по рынку; ${fmt(SIG.CFG.rrWeak)}–${fmt(SIG.CFG.rrMin)} — лимит…`,
     rows:[['Условия','…'],…]}  // необязательные доп. строки (как «Кнопки», «Предупреждения» в артефакте)
  ]
};
```
- `id` — стабильный ключ (латиница, kebab): им пользуются подсказки (`data-g`) и якоря `#gloss=<id>`.
- Для меток приложения — фиксированные id-шки по словарям desk.js: вердикты `v-buy|v-short|v-trim|v-hold|v-wait` (ключи `DK_V`), фазы `ph-<key>` (ключи `DK_PH`), флаги `fl-<key>` (ключи `DK_FLAG`), действия по позиции `act-<key>` (ключи `DK_ACT`). Тест сверяет покрытие.
- `deskGlossText(x)` — разворачивает строку/функцию; `fmt` — число в локали ru (`2` → «2,0» где нужно — брать `dkN`).

## G2 — подсказки на экранах (сессия 2, после проверки G1)
1. **Разметка:** атрибут `data-g="<id>"` у меток: `dkPill` (вердикты), `dkPhase`, `dkFlags`, `dkActPill`, `dkSide`, `dkRiskMeter`; у заголовков KPI (`kpi()` на «Сегодня», «Позиции», «Журнал»), у подписей плана сделки (Вход/Лимит, Стоп, Цель, R/R, «Риск, kr»), у статуса «Что если?», у «Моя зона покупки», «Справедливая стоимость», «Апсайд», «R сейчас», «Открытый риск книги», «Балл», «Рост бизнеса», «Аналитики и оценка», «История сигналов», «Лестница уровней».
2. **Поведение (одна глобальная всплывашка `#dkTip`):**
   - мышь (`pointer:fine`): наведение на `[data-g]` 400 мс → поповер с термином, первым предложением `d` и кнопкой «Подробнее в словаре →» (`deskGlossOpen(id)`); уход курсора с метки и поповера → скрыть через 150 мс. Клики по строкам/карточкам работают как раньше.

- **Мелкие изменения:** у `dkPhase` снят `title` со SMA (иначе две всплывашки; тренд — в «Сигнале» и в словаре); `title` у стопа/цели плана перенесён на подпись источника; у полосы прогресса позиции и «live» title заменён подсказкой. Восстановление фокуса в `deskPaint` учитывает `data-g` и индекс среди одинаковых кнопок.
- **Стили:** бледный пунктир у подписей с подсказкой (только `hover:hover`, ярче при наведении; пилюли/флаги/кликабельные заголовки — без), `-webkit-touch-callout:none`/`user-select:none` на `[data-g]` при `hover:none`, ⓘ 15 px с зоной касания ~31 px, `.dk-tip` z-index 65 (над модалкой 60, под словарём 70).
- **Тесты:** группа `desk glossary: подсказки на экранах (G2)` — скан литералов desk.js (≥ 60), id всех меток по ключам словарей, `dkPill('buy')` → `v-buy`, «Перегрев»/«Сократить» → `v-trim`, фолбэки, фаза без title, ⓘ, тексты подсказок (rr, короткое + второе, сущности, пороги из CFG), у всех 102 записей подсказка ≤ 320 знаков без HTML, экранирование, `deskTipPos` (снизу/сверху/края/400 px). app 815 → 839, `MIN_CASES_app` 770 → 790. Дословных сравнений HTML меток в старых тестах не было — менять не пришлось.
- **Живая проверка** (headless Chrome через CDP, `?desk=1`, admin, 376/391 сигналов): наведение на «▲ Купить» — через 200 мс нет, через 550 мс есть, уход — скрыта; клик по пилюле выбирает карточку, как раньше; ⓘ у KPI — закреплена, переживает движение мыши и `deskPaint()`; «Подробнее» → словарь на `dkg-setups` с подсветкой, Esc → фокус на ту же ⓘ; Enter на ⓘ → фокус на «Подробнее», Esc → назад; клик мимо скрывает; ⓘ в `<summary>` не сворачивает блок; смена экрана скрывает; наведение на `th` «R сейчас»; светлая и тёмная темы; 400 px с касанием: долгое нажатие — подсказка без выбора карточки, тап мимо скрывает, короткий тап выбирает карточку, ⓘ по тапу, горизонтальной прокрутки нет. Ошибок в консоли нет. Действие позиции наведением вживую не проверено — в локальном бандле нет позиций (покрыто тестом разметки).

## Не входит
- Английские тексты описаний (решение пользователя).
- Обучающий тур / онбординг по шагам.
- Подсказки в классических экранах (старые экраны живут до S7b).
- Синк состояния словаря в снапшот (открыт/поиск — только в памяти сессии).

## Риски
- **Разъезд текста и кода:** закрывается принципом 2 и тестом покрытия меток; новые метки без записи ловит тест G2.
- **Размер:** ~95 записей ≈ 50–60 КБ JS, грузится `defer` и кэшируется SW — приемлемо; при заметной задержке первого рендера — вынести в ленивую загрузку по первому открытию (решение в G1 по факту замера).
- **Конфликт жестов на телефоне:** долгое нажатие не должно открывать системное меню — `-webkit-touch-callout:none` на `[data-g]`, `contextmenu` на них гасить.
