# Калибровка слоя сигналов v2 (теневой режим S4)

Статус: **наблюдение идёт с 2026-09-10** (S4, `plans/redesign-integration.md` слой 3). Решение по порогам принимает пользователь по этому файлу, не код (риск «Расхождение вердиктов» §8 плана слияния). После решения — сессия калибровки (правки только в `SIG.CFG`/правилах `signals.js` + тесты), затем S7 удаляет старые движки.

## 1. Как собирать наблюдения (1–2 недели)

1. Во вкладках, по которым принимаете решения (свой портфель, OMXS30, Nasdaq 100, S&P 500 …), откройте **⚙ Колонки → «Вердикт v2»** (только десктоп; на телефоне доп. колонки скрыты). Колонку можно отсортировать: группа вердикта → R/R → балл.
2. Каждый торговый день хотя бы раз откройте эти вкладки (и Home — в «🏆 общем рейтинге» есть столбец **v2** для топ-12). Свечи грузятся фоном (`?history=…&range=2y`, пул 4, кэш 10 мин общий с графиком карточки).
3. Журнал тени пишется **в этот браузер** (`localStorage.dash_sig_shadow`, 14 дней, последний снимок бумаги за день). В других браузерах/устройствах — свой журнал.
4. Раз в несколько дней: **⚙ Колонки → «📋 Отчёт расхождений v2»** — markdown копируется в буфер (и показывается в окне). Вставьте его в §4 ниже с датой.
5. Для разбора конкретной бумаги — подсказка на пилюле v2: причины, план (вход/стоп/цель с источниками уровней, qty по риску 1 % капитала), флаги, «≠» при расхождении со старой «Рекомендацией».

Что сравнивается: старая «Рекомендация» списка (`pf3Reco`: buy/wait/sell/avoid), вердикт карточки «Сейчас» (`pf3RecoHorizons.now`), бейдж «Критерий» (`pf3Criterion`) ↔ вердикт v2 (buy/short/trim/hold/wait), `phase` v2, R/R и режим входа. Совпадение — по грубым классам: вход (buy) / выход (sell ↔ trim, short) / вне рынка (wait ↔ hold, wait); старый avoid совпадает с любым «не покупать».
