# Портфель v2 — альтернативная версия (Svelte + Vite + TS + Tailwind)

Чистый трекер в стиле **Ghostfolio** поверх **существующего** бэкенда: тот же
Cloudflare Worker (живые цены) и Supabase (`ledger_state`). Текущий сайт в корне
репозитория не трогается — v2 раздаётся рядом, по пути `/v2/`.

## Зачем
Текущий сайт — один `app.js` на ~5500 строк без сборки и компонентов. v2 — это
тот же функционал, но с нормальной архитектурой: дизайн-система (токены),
компоненты, типы, модульные границы. Комфортно дорабатывать.

## Стек
- **Svelte 4** + **Vite 5** + **TypeScript** + **Tailwind 3**
- `@supabase/supabase-js` — чтение снапшота пользователя (RLS защищает данные)
- Сборка статическая → `../v2`, деплой через GitHub Actions (`.github/workflows/v2.yml`)

## Структура
```
v2-src/
  src/
    lib/         данные и логика (без UI)
      config.ts    боевые эндпоинты (Worker URL, Supabase)
      types.ts     доменные типы (Position, Portfolio, Snapshot)
      supabase.ts  клиент + чтение ledger_state
      snapshot.ts  парсинг снапшота текущего сайта → портфели (по именам колонок)
      api.ts       Worker: exSymbol + живые котировки (?symbols=)
      calc.ts      агрегаты: статистика, аллокации, лидеры дня
      data.ts      оркестрация: сессия → ledger → парсинг → живые цены
      format.ts    деньги/проценты/цвета
      i18n.ts      RU/EN ($t, $rt)
      stores.ts    svelte-сторы (тема, язык, маршрут, снапшот)
      toast.ts     тосты
    components/  переиспользуемые: Card, StatCard, Delta, AllocationBars,
                 HoldingsTable, Sidebar, Topbar, Toasts
    routes/      экраны: Dashboard, Holdings, Login
    App.svelte   оболочка (nav + topbar + роутинг + bootstrap авторизации)
    app.css      дизайн-токены (CSS-переменные) + Tailwind
```

## Данные (реальные)
1. Логин тем же аккаунтом, что и на основном сайте (Supabase email+пароль).
2. `data.ts` читает `ledger_state.data` → `snapshot.ts` нормализует позиции
   (колонки находятся **по имени заголовка**, поэтому устойчиво к разным наборам
   колонок у разных портфелей).
3. Живые цены подтягиваются с воркера (`?symbols=`); кнопка «🔄 Обновить цены».

## Локальная разработка (нужен Node 18+/20)
```bash
cd v2-src
npm install
npm run dev      # http://localhost:5173
npm run build    # → ../v2
npm run check    # svelte-check (типы)
```

## Деплой
Пуш в `main` с изменениями в `v2-src/**` запускает workflow **Build v2**: он
собирает и коммитит статику в `/v2`. Classic Pages раздаёт `/v2/` рядом с текущим
сайтом. Локальный Node не обязателен — всё собирает CI.
